# Как выложить и обновлять сайт с документами

## Первый запуск (один раз, ~10 минут)
1. github.com → New repository → имя `docs` → Public → Create.
2. «uploading an existing file» → перетащить ВСЁ содержимое папки сайта (папки offer, privacy, docs, fonts, файлы index.html, style.css, theme.js, logo.png, .nojekyll) → Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка /(root) → Save.
4. Там же, Custom domain: ввести `docs.ВАШ-ДОМЕН.ru` → Save. Поставить галочку Enforce HTTPS, когда станет доступна.
5. Добавить DNS-запись: тип CNAME, имя `docs`, значение `ВАШ-ЛОГИН.github.io`. Если домен управляется через Netlify (Domains → DNS records → Add new record), добавляйте там; иначе у регистратора домена. Основной сайт на Netlify не затрагивается, нужен именно поддомен.
6. Через 5–30 минут документы открываются по ссылкам:
   - docs.ВАШ-ДОМЕН.ru/offer/
   - docs.ВАШ-ДОМЕН.ru/privacy/

## Как обновить документ
Открыть файл в репозитории, например docs/privacy.md → карандаш → поправить текст → Commit changes. Сайт обновится через 1–2 минуты.
Либо: Add file → Upload files → загрузить новый privacy.md с тем же именем.
Дату редакции на главной менять в docs/docs.json.

## Как добавить новый документ
1. Загрузить docs/consent.md (текст в Markdown: # заголовок, ## раздел, - пункт списка).
2. Создать папку consent с файлом index.html (копия offer/index.html).
3. Добавить строку в docs/docs.json.
